Python Number Guessing Game

About the Project

This is a beginner-friendly Python game in which the player tries to guess a randomly generated number between 1 and 10.

Features

* Random number generation
* Three attempts to guess the correct number
* Hints when the guess is too high or too low
* Win and game-over messages

Technologies Used

* Python
* Random module
* Loops and conditional statements

How to Play

1. Run the Python program.
2. Enter a number between 1 and 10.
3. Follow the hints to guess the correct number.
4. You have three attempts to win!

What I Learned

* Using variables and the random module
* Applying while loops and if-else statements
* Using break to stop a loop
* Taking user input and displaying output
